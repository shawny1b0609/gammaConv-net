# Contributing

Please open an issue before proposing a change to the model equations or the experiment protocol. For a bug report, include the command, dependency versions, and a small reproducible example without private data.

Run `python -m unittest discover -s tests -v` before submitting a change. Describe any change to data handling, loss functions, parameter constraints, or validation selection; these can affect scientific interpretation.

Contributions must be your own work, or work you have permission to contribute. By submitting a contribution for inclusion, you agree to license it under this repository's Noncommercial Research License. You retain copyright in your contribution. Do not include personal data, unlicensed datasets, credentials, or local filesystem paths.
